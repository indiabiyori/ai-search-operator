# Perplexity（`perplexity`）はこのスキルでは観測しない

一般向けの画面で Perplexity に尋ねて記録する観測は、手動であっても、このスキルでは扱わない（2026-09-27 に決定）。観測の計画にもプロンプトセットの例にも入れず、new_round.py でひな形も作らない。ユーザーに観測を頼まれたら、非対応だと伝え、ほかのサービス（[03-observation.md](../03-observation.md) の「サービスごとの既定の案」）を案内する。

service の値 `perplexity` は、すでに記録した回答ファイルを normalize_observations.py で読めるようにするためだけに残してある。新しい観測には使わない。

このファイルは利用規約の文面をまとめたもので、法的な判断ではない。自社の使い方が規約に触れるかは、弁護士などの専門家に確認する。

## 非対応にした理由

このスキルの観測では、利用者が画面で同じ質問を繰り返し尋ね、回答と出典を回答ファイルに写し、自社の言及と引用を数える。一般向けの利用規約（資料1）とは、次の3点で合わない。

- 利用の目的: 5.1 は、利用を個人の非営利目的に限っている。このスキルは、事業者が自社や担当先のブランドの扱われ方を追うために使う。
- 手作業による監視・収集: 5.2(i) は、監視・抽出・コピー・収集のために自動の手段を使うことに加えて、同様の目的で手動のプロセスに従事することも禁じている。画面で尋ねて回答を記録する観測は、この手動のプロセスに当たるおそれがある。
- 情報のコピー: 5.2(a) は、本サービスを通じて取得した情報のダウンロードやコピーを、ブラウザの表示のための一時ファイルと規約で明示的に許可された場合を除いて禁じている。回答を回答ファイルに写す作業は、これに当たるおそれがある。

例外もある。5.2 の禁止は、適用法や規制がこれらの制限を禁止している場合と、Perplexity の書面による許可がある場合には当てはまらない。

## 利用規約の要点

Perplexity の利用規約（日本語版、最終更新日 2026-01-23。資料1。2026-09-27 にブラウザで本文を確認）のうち、観測にかかわる箇所。

- 冒頭: この規約は、API（Perplexity API 利用規約、資料2）と Perplexity Pro for Enterprise（資料3）の利用には適用されない。
- 5.1: 「当社は、お客様がすべての利用に関連して本規約を遵守することを条件として、お客様個人の非営利目的での利用に限り、本サービスの利用を許可します。」
- 5.2 の冒頭: 「適用法や規制がこれらの制限を禁止している場合、または当社の書面による許可がある場合を除き、本サービスの利用に関連して以下のいかなる行為も行ってはなりません」
- 5.2(a): 「本サービスに含まれる、または本サービスを通じて取得した情報を、ブラウザの表示のための一時ファイルと本規約で明示的に許可された場合を除き、ダウンロード、変更、コピー、配布…すること」
- 5.2(i): 「本サービスを監視、抽出、コピー、または収集するために…自動デバイス、プロセス、ソフトウェア、またはクエリを使用すること、あるいは同様の目的のために手動プロセスに従事すること」

## API や Enterprise の規約、書面の許可がある場合

一般向けの利用規約は、API と Perplexity Pro for Enterprise には適用されない。これらを使う場合や、Perplexity から書面による許可を得ている場合は、その規約や許可が観測の目的と方法を認めているかを、利用者が確かめる。API と Enterprise の規約の中身は、このスキルでは確かめていない。

- 利用者が確かめるまでは、観測の計画に入れない。確かめたら、規約か許可の名前、確認日、観測を認める根拠の箇所を brief.md の「観測の条件の決まり」に書いてもらう。確かめていない間は `[要確認: Perplexity の API 利用規約・Enterprise の規約・書面の許可が、観測の目的と方法を認めているか]` と書く。
- このスキルの手順（03-observation.md と services/ の各ファイル）は一般向けの画面を前提にしていて、API や Enterprise での条件のそろえ方は書いていない。API による自動の収集も、このスキルの範囲外（03 の[「自動取得をしない理由」](../03-observation.md#自動取得をしない理由)）。
- 法的な判断は専門家に確認する。
